# ஏற்கனவே சேர்க்கப்பட்டவை மற்றும் எதிர்கால வசதிகள்

## இப்போது உள்ளவை
- Contact மற்றும் Corporate Gifting form செய்திகள் database-ல் சேமிக்கப்படும் -> Admin **Messages** page
- Orders மற்றும் Customers-ஐ Excel (CSV) ஆக download
- SEO: sitemap.xml, robots.txt (தானாக), LocalBusiness data, விருப்ப Google Analytics
- பல domain-களுக்கு CORS அனுமதி, `.env.example` கோப்புகள்

## பின்னால் சேர்க்கக்கூடியவை (தேவைப்படும்போது சொல்லுங்கள்)
1. Order வந்தவுடன் உங்களுக்கு Email / Telegram அறிவிப்பு
2. Product photos-ஐ Cloudflare R2-ல் சேமித்தல் (அதிக photos இருந்தால் தேவை)
3. GST invoice PDF (order-ல் இருந்து நேரடியாக)
4. Bulk விலை அடுக்கு (எ.கா. 100+ க்கு குறைந்த விலை)
5. Product-க்கு பல photos, தமிழ்/ஆங்கில மொழி மாற்றம்
6. பல admin பயனர்கள், password மாற்றும் page
7. Coupon / தள்ளுபடி குறியீடுகள்
8. Customer-க்கு order status WhatsApp அறிவிப்பு (WhatsApp Business API)
